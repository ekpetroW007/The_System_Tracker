# The System

Персональное Android-приложение для дисциплины, учёбы и личного бюджета. Ежедневный контур начинается с пяти направлений:

- **УТРО:** 20 отжиманий после подъёма с простой ежедневной отметкой «да» / «нет».
- **СВЕТ:** 30-дневный план привыкания к свету, который завершается и исчезает из ежедневного стандарта;
- **ПИТАНИЕ:** день без сладкого и чипсов;
- **ВОДА:** учёт по 0,25 л до дневной цели 2,5 л;
- **СОН:** цифровой отбой в 22:45 и в кровати в 23:30.

## Возможности

- бинарная отметка «да» / «нет» для 20 утренних отжиманий;
- причины нарушения сна с разделением на цифровой отбой и время в кровати;
- календарь с редактированием прошлых дней;
- честная статистика: отдельно соблюдение и полнота заполнения;
- анализ причин и взаимосвязей за последние 30 дней;
- динамический дизайн, сворачивание выполненных карточек и режим восстановления;
- режим ВШЭ с выбранным Android-календарём, ближайшей парой, автобусным маршрутом и заданиями;
- режим «БЕГ» с подтверждением, секундомером, анимацией, плейлистом Яндекс Музыки и итогами пробежки;
- четыре графитово-платиновых виджета с прямыми переходами к нужному действию;
- локальные напоминания, которые не приходят после уже сделанной отметки;
- три музыкальных будильника цифрового отбоя: в заданное время, через 2 и через 4 минуты; каждый запускает `FRIENDLY THUG 52 NGG — Sladki Snov Rapper 2` через Яндекс Музыку;
- утренний запуск исполнителя дня в Яндекс Музыке как опциональная best-effort функция Android;
- Money с обязательными тратами, редактированием, быстрым повтором, прогнозом и CSV;
- локальная SQLite-база без аккаунта и банковской синхронизации;
- зашифрованный паролем экспорт и восстановление данных; Android Auto Backup отключён;
- персональные анимации выполнения и facepalm-анимация после нарушения;
- Liquid Glass-иконка с прицелом и галочкой;
- адаптивный тёмный интерфейс Jetpack Compose, TalkBack-описания и режим сокращённых анимаций.

Домашний адрес хранится локально, но при построении маршрута передаётся Яндекс Картам. Ключ MapKit в репозиторий не входит.

## Готовый APK

Для ручного тестирования используется arm64 APK с внутренней подписью разработчика. Публичный release должен быть подписан постоянным ключом владельца приложения; Gradle не разрешает production-сборку без такой конфигурации.

## Сборка

Проект использует Android SDK 36, JDK 17, Kotlin и Jetpack Compose.

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME='C:\Users\user\AppData\Local\Android\Sdk'
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
.\gradlew.bat assembleDebug -PtargetAbi=arm64-v8a
.\gradlew.bat assembleRelease -PtargetAbi=arm64-v8a
```

Для release создай локальный `keystore.properties` по образцу `keystore.properties.example`. Вместо файла можно использовать переменные окружения `THE_SYSTEM_KEYSTORE`, `THE_SYSTEM_STORE_PASSWORD`, `THE_SYSTEM_KEY_ALIAS` и `THE_SYSTEM_KEY_PASSWORD`. Секреты и ключи подписи игнорируются Git.

Техническая unsigned-сборка разрешается только явным флагом `-PallowUnsignedRelease=true` и не предназначена для распространения.

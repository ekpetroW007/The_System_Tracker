# The System

Персональное Android-приложение для ежедневного контроля пяти направлений:

- **УТРО:** 14 уровней от 10 до 20 отжиманий; следующий уровень открывается только после выполнения предыдущего, затем закрепляется постоянный стандарт 20 подряд.
- **СВЕТ:** 30-дневный план привыкания к свету;
- **ПИТАНИЕ:** день без сладкого и чипсов;
- **ВОДА:** учёт по 0,25 л до дневной цели 2,5 л;
- **СОН:** цифровой отбой в 22:45 и в кровати в 23:30.

## Возможности

- ежедневный чек-ин с отменой выбранного ответа повторным нажатием;
- причины нарушения сна и питания;
- календарь с редактированием прошлых дней;
- статистика за 30 дней, анализ причин и недельный управленческий отчёт;
- динамический дизайн, сворачивание выполненных карточек и режим восстановления;
- режим ВШЭ с первой парой, временем выхода и главной учебной задачей;
- виджет с прогрессом дня и быстрым добавлением 0,25 л воды;
- изменяемое расписание;
- локальные напоминания об отбое, подготовке ко сну и утренних отжиманиях;
- локальное хранение данных без аккаунта и интернета;
- персональные анимации выполнения и facepalm-анимация после нарушения;
- Liquid Glass-иконка с прицелом и галочкой;
- темный интерфейс Jetpack Compose, анимации и тактильная обратная связь.

## Готовый APK

Установочный APK доступен в разделе **Releases** репозитория. Это release-сборка приложения, подписанная сертификатом текущей среды разработки и предназначенная для ручной установки. Для публикации в магазине потребуется отдельный постоянный release-ключ.

## Сборка

Проект использует Android SDK 36, JDK 17, Kotlin и Jetpack Compose.

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME='C:\Users\user\AppData\Local\Android\Sdk'
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleRelease
```

Неподписанный результат release-сборки: `app\build\outputs\apk\release\app-release-unsigned.apk`.

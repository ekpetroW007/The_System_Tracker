# The System

Персональное Android-приложение для ежедневного учета двух решений:

- **СОН:** цифровой отбой в 22:45 и в кровати в 23:30;
- **УТРО:** 14-дневный режим допуска от 10 до 20 отжиманий, затем постоянный стандарт 20 подряд.

## Возможности

- ежедневный чек-ин «СОН — да/нет» и «УТРО — да/нет»;
- причины нарушения: телефон, ноутбук, устал, грустно, другое;
- календарь с редактированием прошлых дней;
- соблюдение за 30 дней, недельный обзор и анализ причин;
- изменяемое расписание;
- локальные напоминания об отбое, подготовке ко сну и утренних отжиманиях;
- локальное хранение данных без аккаунта и интернета;
- конфетти после «ДА» и facepalm-эмодзи после выбора причины нарушения;
- Liquid Glass-иконка с прицелом и галочкой;
- темный интерфейс Jetpack Compose, анимации и тактильная обратная связь.

## Готовый APK

Установочный APK доступен в разделе **Releases** репозитория. Это release-сборка приложения, подписанная сертификатом текущей среды разработки и предназначенная для ручной установки. Для публикации в магазине потребуется отдельный постоянный release-ключ.

## Сборка

Проект использует Android SDK 36, JDK 17, Kotlin и Jetpack Compose.

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME='C:\Users\user\AppData\Local\Android\Sdk'
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleRelease
```

Неподписанный результат release-сборки: `app\build\outputs\apk\release\app-release-unsigned.apk`.
